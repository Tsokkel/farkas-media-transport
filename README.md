# Farkas Media & Transport – Website

Onepager für **Farkas Media & Transport** (Inhaber Istvan Farkas, Ennepetal):
Werbetechnik sowie Fahrzeugtransporte & Überführungen europaweit.

Live: https://www.farkas-media-transport.com (über GitHub Pages, Domain bei IONOS)

## Aufbau
- `index.html` – Startseite (Onepager)
- `impressum.html`, `datenschutz.html` – Rechtstexte
- `assets/` – Logo, Favicon, Stylesheet
- `CNAME` – eigene Domain für GitHub Pages

Reines HTML/CSS ohne Build-Schritt, ohne externe Schriften, ohne Cookies/Tracking.
